השרת והלקוח מופעלים ברקע, אבל יש דבר אחד חשוב שצריך לעשות:

═══════════════════════════════════════════════════════════════
  שלב 1: מסד נתונים MySQL (חובה!)
═══════════════════════════════════════════════════════════════

לפני שהכל יעבוד, צריך ליצור את מסד הנתונים:

1. פתח MySQL Workbench או phpMyAdmin
2. פתח את הקובץ: backend/database/schema.sql
3. העתק את כל התוכן
4. הדבק ב-MySQL והרץ

זה ייצור:
- מסד הנתונים vacation_db
- כל הטבלאות (users, vacations, follows)

═══════════════════════════════════════════════════════════════
  שלב 2: יצירת משתמש אדמין
═══════════════════════════════════════════════════════════════

לאחר יצירת מסד הנתונים, הרץ:

cd Vacation-STUDENT_ID\backend
node database\initAdmin.js

זה ייצור משתמש אדמין:
- שם משתמש: admin
- סיסמה: admin123

═══════════════════════════════════════════════════════════════
  שלב 3: עדכון קובץ .env
═══════════════════════════════════════════════════════════════

אם יש לך סיסמה ל-MySQL, עדכן את הקובץ:
backend/.env

שנה את השורה:
DB_PASSWORD=הסיסמה_שלך

═══════════════════════════════════════════════════════════════
  מה כבר רץ ברקע:
═══════════════════════════════════════════════════════════════

✅ Backend Server - רץ על פורט 3001
✅ Frontend App - רץ על פורט 3000

אם הדפדפן לא נפתח אוטומטית, פתח:
http://localhost:3000

═══════════════════════════════════════════════════════════════
  בדיקת תקינות:
═══════════════════════════════════════════════════════════════

1. בדוק שהשרת רץ:
   → פתח: http://localhost:3001
   → צריך לראות שגיאה או "Cannot GET /" (זה תקין!)

2. בדוק שהלקוח רץ:
   → פתח: http://localhost:3000
   → צריך לראות דף התחברות

3. אם יש שגיאת מסד נתונים:
   → ודא ש-MySQL רץ
   → ודא שיצרת את מסד הנתונים (schema.sql)
   → ודא שהסיסמה ב-.env נכונה

═══════════════════════════════════════════════════════════════
  סדר פעולות מומלץ:
═══════════════════════════════════════════════════════════════

1. ✅ הרץ את schema.sql ב-MySQL
2. ✅ עדכן את DB_PASSWORD ב-backend/.env
3. ✅ הרץ: node database/initAdmin.js
4. ✅ פתח: http://localhost:3000
5. ✅ התחבר עם admin/admin123
