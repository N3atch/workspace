═══════════════════════════════════════════════════════════════
  ⚡ התחלה מהירה:
═══════════════════════════════════════════════════════════════

שלב 1: MySQL
  → הרץ את: backend/database/schema.sql

שלב 2: Backend .env
  → צור: backend/.env
  → העתק מ: backend/.env.example (אם קיים)
  → עדכן את סיסמת MySQL

שלב 3: יצירת אדמין
  → cd backend
  → node database/initAdmin.js

שלב 4: הפעלת Backend
  → cd backend
  → npm start

שלב 5: Frontend .env
  → צור: frontend/.env
  → העתק מ: frontend/.env.example (אם קיים)

שלב 6: הפעלת Frontend
  → cd frontend
  → npm start
