═══════════════════════════════════════════════════════════════

⚠️ שלב 1: מסד נתונים MySQL (חובה!)

1. פתח MySQL Workbench או phpMyAdmin
2. פתח את הקובץ: backend/database/schema.sql
3. העתק את כל התוכן והרץ ב-MySQL

זה ייצור את מסד הנתונים ואת כל הטבלאות.

═══════════════════════════════════════════════════════════════

⚠️ שלב 2: עדכון סיסמת MySQL

אם יש לך סיסמה ל-MySQL:
1. פתח את הקובץ: backend/.env
2. עדכן את השורה: DB_PASSWORD=הסיסמה_שלך

אם אין לך סיסמה, השאר ריק (DB_PASSWORD=)

═══════════════════════════════════════════════════════════════

⚠️ שלב 3: יצירת משתמש אדמין

לאחר יצירת מסד הנתונים, הרץ:

cd Vacation-STUDENT_ID\backend
node database\initAdmin.js

זה ייצור משתמש אדמין:
- שם משתמש: admin
- סיסמה: admin123

http://localhost:3000

═══════════════════════════════════════════════════════════════
  בדיקת תקינות:
═══════════════════════════════════════════════════════════════

✅ השרת רץ?
   → פתח: http://localhost:3001
   → צריך לראות שגיאה או "Cannot GET /" (זה תקין!)

✅ הלקוח רץ?
   → פתח: http://localhost:3000
   → צריך לראות דף התחברות

✅ מסד נתונים מוכן?
   → הרץ את schema.sql ב-MySQL
   → הרץ את initAdmin.js
   → נסה להתחבר

═══════════════════════════════════════════════════════════════
  פתרון בעיות:
═══════════════════════════════════════════════════════════════

❌ "Cannot connect to database"
   → ודא ש-MySQL רץ
   → ודא שיצרת את מסד הנתונים (schema.sql)
   → בדוק את הסיסמה ב-backend/.env

❌ "Port 3001 already in use"
   → השרת כבר רץ (זה טוב!)
   → או סגור תהליכים קודמים

❌ "Port 3000 already in use"
   → הלקוח כבר רץ (זה טוב!)
   → או סגור תהליכים קודמים
