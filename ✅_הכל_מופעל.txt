שלב 1: התקן MySQL (אם לא מותקן)
──────────────────────────────────

1. הורד MySQL מ: https://dev.mysql.com/downloads/installer/
2. התקן MySQL Server
3. זכור את הסיסמה שיצרת
4. עדכן את backend/.env עם הסיסמה

שלב 2: צור את מסד הנתונים
───────────────────────────

לאחר התקנת MySQL, פתח PowerShell והרץ:

cd Vacation-STUDENT_ID\backend
node setup-database.js

זה ייצור:
- מסד הנתונים vacation_db
- כל הטבלאות
- משתמש אדמין (admin/admin123)

שלב 3: נסה להתחבר
───────────────────

1. בדפדפן שנפתח (http://localhost:3000)
2. התחבר עם:
   - שם משתמש: admin
   - סיסמה: admin123
