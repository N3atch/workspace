שלב 1: הפעל MySQL
───────────────────

אפשרות א' - דרך Services:
1. לחץ Win + R
2. הקלד: services.msc
3. מצא MySQL והפעל

אפשרות ב' - דרך CMD (כמנהל):
   net start MySQL

שלב 2: צור את מסד הנתונים
───────────────────────────

cd Vacation-STUDENT_ID\backend
node setup-database.js

זה ייצור הכל אוטומטית!

שלב 3: בדוק שהכל עובד
