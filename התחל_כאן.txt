📖 לקריאה מפורטת: פתח את הקובץ "מדריך_הפעלה_מפורט.md"

═══════════════════════════════════════════════════════════════
  שלב 1: מסד נתונים MySQL
═══════════════════════════════════════════════════════════════

1. פתח MySQL Workbench או phpMyAdmin
2. הרץ את הקובץ: backend/database/schema.sql
   (או העתק את התוכן והרץ ב-MySQL)

═══════════════════════════════════════════════════════════════
  שלב 2: הגדרת Backend
═══════════════════════════════════════════════════════════════

1. עבור לתיקייה: backend/
2. צור קובץ .env (העתק מ-.env.example)
3. עדכן את הסיסמה של MySQL בקובץ .env
4. הרץ: node database/initAdmin.js

═══════════════════════════════════════════════════════════════
  שלב 3: הפעלת Backend (חלון טרמינל 1)
═══════════════════════════════════════════════════════════════

cd Vacation-STUDENT_ID\backend
npm start

✅ צריך לראות: "Server running on port 3001"

═══════════════════════════════════════════════════════════════
  שלב 4: הגדרת Frontend
═══════════════════════════════════════════════════════════════

1. עבור לתיקייה: frontend/
2. צור קובץ .env (העתק מ-.env.example)

═══════════════════════════════════════════════════════════════
  שלב 5: הפעלת Frontend (חלון טרמינל 2)
═══════════════════════════════════════════════════════════════

cd Vacation-STUDENT_ID\frontend
npm start

✅ הדפדפן ייפתח אוטומטית על http://localhost:3000
